Star and Exoplanet Research Group (SERG)

Software and pipelines

Open-source tools developed by group members for retrieving, processing and analysing astronomical data. Each is free to use, with its code and documentation on GitHub.

Using our software

The tools are released under open-source licences. If they help your research, please cite them and the packages they build on, and tell us about it: feedback guides what we build next.

Contributing

Bug reports and suggestions are welcome through each project's GitHub page. Students interested in scientific software projects can write to us about joining the group.
